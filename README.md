# MelodyRecognizer

Проект для распознавания мелодий на C++.

Программа реализует упрощённую систему распознавания музыки по спектральным отпечаткам (audio fingerprints), вдохновлённую принципами работы приложений вроде Shazam.

Основная идея проекта:
- считать WAV-файл,
- разложить сигнал по частотам с помощью преобразования Фурье,
- построить компактный спектральный отпечаток,
- сравнить его с базой данных известных мелодий.

# Как работает программа

Программа работает по следующей схеме:

```text
WAV-файл
↓
audio samples
↓
преобразование Фурье
↓
анализ частот
↓
построение fingerprint
↓
сравнение с базой
↓
распознанная мелодия
```

Вместо сравнения WAV-файлов напрямую программа извлекает из сигнала компактное описание — fingerprint.

Это позволяет:
- уменьшить объём данных;
- ускорить сравнение;
- снизить чувствительность к шумам и громкости;
- сравнивать именно музыкальные признаки сигнала.

# Описание модулей

## wav_reader

Модуль для считывания WAV-файлов.

Из WAV-файла извлекаются:
- частота дискретизации;
- количество каналов;
- битность;
- массив audio samples.

Поддерживаемый формат:
- PCM WAV;
- 16-bit audio.

---

## fourier

Модуль, реализующий преобразование Фурье.

Позволяет разложить сигнал на набор частот и определить спектр сигнала.

---

## fingerprint

Модуль построения спектрального отпечатка мелодии.

Сигнал разбивается на небольшие временные окна.  
Для каждого окна определяется доминирующая частота.

Пример fingerprint:

```text
[21, 23, 24, 21]
```

---

## database

Модуль для работы с базой данных мелодий.

Fingerprint каждой мелодии сохраняется в отдельный `.txt` файл.

Файл `database.txt` содержит:
- названия мелодий;
- пути к fingerprint-файлам.

---

## recognizer

Модуль распознавания мелодий.

Сравнивает fingerprint входного сигнала с fingerprint из базы данных и находит наиболее похожую мелодию.

# Сборка проекта

## Требования

- C++17
- CMake
- GCC / MinGW / MSVC

---

## Сборка

Создание папки build:

```powershell
mkdir build
cd build
```

Генерация файлов сборки:

```powershell
cmake ..
```

Компиляция проекта:

```powershell
cmake --build .
```

---

# Обновление базы данных

WAV-файлы базы данных необходимо поместить в папку:

```text
data/wav/database/
```

После этого нужно запустить:

```powershell
.\update_database.exe
```

Программа:
- построит fingerprint для каждой мелодии;
- сохранит fingerprint в `data/fingerprints/`;
- автоматически обновит `database.txt`.

---

# Распознавание мелодии

Файл для распознавания необходимо поместить в:

```text
data/wav/query/query.wav
```

После этого нужно запустить:

```powershell
.\melody_recognizer.exe
```

Программа:
- считает WAV-файл;
- построит fingerprint;
- сравнит его с базой данных;
- выведет наиболее похожую мелодию.

Пример вывода:

```text
Recognized melody: song3
```
